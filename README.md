# SANS AFAAQ Assessment - Preparation Platform ✈️

منصة تدريب تفاعلية وشاملة لإعداد واجتياز اختبار برنامج **"آفاق" (AFAAQ)** لشركة **خدمات الملاحة الجوية السعودية (SANS)** عبر منصة التقييم العالمية **Mercer | Mettl**.

## 🌟 مميزات المنصة:
- **تحليل كامل لمعادلة الاختبار (199 سؤال في 77 دقيقة):** أسرار إدارة الوقت وقواعد المراقبة الحية (Proctoring).
- **مقياس الشخصية وأسلوب العمل (Mettl Personality Profiler):** توجيهات تفصيلية لكشف فخاخ "المثالية المصطنعة" والانسجام مع ثقافة السلامة والملاحة الجوية.
- **الاستدلال المنطقي وسلاسل الأشكال (SVG):** أنماط دوران الزوايا والدمج والاستنتاج المنطقي.
- **القدرة العددية (Mental Math):** أسرار الحساب الذهني للنسب المئوية والسرعة في 15 ثانية.
- **اللغة الإنجليزية المهنية (English Proficiency):** القواعد الشائعة والمفردات التخصصية.
- **المحاكي الواقعي والمؤقت التنازلي:** وضع الـ 77 دقيقة ووضع تدريب السرعة (15 دقيقة).
- **بطاقات المراجعة السريعة (Flashcards):** للمذاكرة الخاطفة من الجوال.
- **دعم صحة وراحة العينين:** الوضع الليلي الدافئ وإمكانية تكبير الخطوط (A- / A+).
